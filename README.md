## Project Overview
This project develops a Python-based Real-time Energy Management Strategy (EMS) for a 2012 Chevrolet Volt Plug-in Hybrid Electric Vehicle (PHEV). The system combines vehicle powertrain modeling, simulation, Genetic Algorithm (GA) optimization, and Deep Learning (DL) to investigate optimal power distribution between the battery and combustion engine.

The project includes:
* System modeling and vehicle powertrain simulation
* Rule-based control as a baseline strategy
* Genetic Algorithm optimization for power-management decisions
* Training-data generation and data analysis
* Deep Learning model development and training
* Prediction of power-management decisions during simulation
* Evaluation against conventional Charge Depleting / Charge Sustaining (CD/CS) strategies
